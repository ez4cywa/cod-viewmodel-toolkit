# 3.6.1 — 原名导入与 CAST 蒙皮导出修复

Maya 默认模型导入不再添加 `cast_import:` 前缀。CAST 模型导出改用完整 DAG 身份
区分骨骼，避免不同分支的同名骨骼合并后丢失或错绑权重，并明确保留线性／双四元数
蒙皮方式。升级时请完整替换工具包运行文件，保存工作后重启 Maya；只替换主入口
不足以更新内置转换器。

## 原名导入与重复模型

**导入 CAST…** 和内置模型拖放首次保留模型、骨骼及材质原名。名称冲突时只在
原名称末尾追加数字，例如 `j_gun` → `j_gun1`、`bone7` → `bone71`；不会替换原名称
已有的数字，不会给整个模型添加固定前缀。

内部仍先隔离创建，再保留各节点的真实连接进行命名，导入后清除临时命名空间。
重复导入的模型拥有各自的骨骼、材质和蒙皮连接，不复用或改绑场景中的同名对象。
已有 Python API 显式传入 `namespace` 的调用继续兼容；单／双武器构建器原有挂载
约定、双持持久前缀和安全动画目标映射不因此改变。

本改动不批量重命名用户已经打开的旧场景，也不修改源 CAST。普通 Maya
**文件 → 导入** 或外部 `Cast` 转换器仍不是工具包统一入口。

在用户提供的握把模型上，旧版 3.6.0 已安装入口的默认导入／导出流程复现了组名
漂移：原骨骼 `tag_pistolgrip_attach` 首次导入后成为
`cast_import:tag_pistolgrip_attach`；导出将这个名称写入 CAST，再次导入时，
名称规范化先把冒号转换为下划线，默认入口又添加命名空间，最终成为
`cast_import:cast_import_tag_pistolgrip_attach`。

这是可见骨骼／顶点组名称发生变化的直接证据，不能仅凭名称变化断言数值权重
已经错位。本版默认入口不再留下该前缀，导入、导出、再导入和再导出保持原骨名。
已有旧场景或显式 namespace 调用仍可能带有命名空间；本版不会自动清理它们，
也不承诺任意外部命名空间场景都能完全原名往返。

## 蒙皮导出修复

与上述名称漂移独立的已复现错误位于 Maya CAST 导出器：此前以骨骼短名作为
`uniqueBones` 的键。
不同 DAG 分支的同名骨骼会落到同一条记录，其骨骼索引和顶点权重可能丢失或指向
错误骨骼。这不是靠删除 `cast_import:` 显示名称就能解决的问题。

现在按完整 DAG 路径维护骨骼、父索引和蒙皮影响项的对应关系。导出文件内需要
唯一名称时只追加数字，工作场景的名称、骨架层级和权重保持不变。导入器仍按
CAST 骨骼索引建立权重，不依赖新生成名称的排序。

此前通用模型导出没有写出蒙皮方式，DQS 模型重新导入时可能回落为默认线性蒙皮。
本版明确输出 `linear` 或 `quaternion` 网格标记；动画批量导出原有 DQS 策略不变，
纯静态导出不强制把线性模型转成 DQS。

有实际权重的影响项未包含在导出骨架中、非关节影响项带有效权重，或使用 CAST
无法等价表达的混合线性／DQS 蒙皮时，会明确拒绝导出，而不是静默把权重指向
第 0 根骨骼。请补全导出选择，或先在场景副本中改用受支持的纯线性／纯 DQS
蒙皮；工具包不会替用户修改原场景来掩盖这些差异。

动画导出另采用保守边界：所选导出范围存在同叶名骨骼时，在写文件前明确拒绝。
仅动画导出、或其中部分同名骨骼没有关键帧，也遵守此规则，避免产生无法确定
对应骨骼的轨道。静态模型可在文件内唯一化重名骨骼，不代表动画轨道也能安全
猜测对应关系；需要此类动画时，请先在场景副本中使用唯一骨名。

## 空材质引用与 Blender 范围

共享序列化器的 Mesh/Hair 可选材质引用在存在但值为空时返回 `None`，不再直接
访问不存在的第一项。Maya 无材质网格使用默认材质；文件中缺失的贴图不会因此
被恢复。有效、缺失和无法解析的材质引用原有行为不变，二进制格式不变。

这项读取修复同时随 Blender 安装包分发。Blender 本版只对齐版本并接收共享的
空材质读取修复，没有加入上述 Maya 命名策略或权重导出修复；不将 Maya 的验收
结论视为 Blender 蒙皮正确性的证明。
