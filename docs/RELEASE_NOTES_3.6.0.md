# 3.6.0 — Optional Maya outputs and standalone FBX/SMD exports

Maya 的 MA、CAST、FBX、SMD 输出默认全部关闭。不选输出格式时，单武器、双持
及快速挂载只在当前场景完成组装，不创建输出目录、JSON、模型文件或米制导出进程。
需要文件时再勾选格式，或使用菜单中的单独导出工具。

首次读取旧版保存设置时，只迁移四项输出勾选为关闭；模型路径、骨骼映射、目录及
其他设置保留。此后手动选择的格式仍会正常保存。动画批量导出及多武器批处理仍需
至少选择一种输出，避免队列只留下最后一个内存场景。

## 内置 CAST 导入

菜单新增 **Import CAST... / 导入 CAST…**，无需加载独立 `castplugin.py`。
只含模型的文件导入新的 `cast_import` 命名空间，重名时自动加后缀，不自动挂载、
不清零关节。节点创建与名称查询均隔离；内置 Maya 导入器另修复材质名称限定，
避免相对名称模式误查已有根材质。复用上游序列化与导入实现，没有另写 CAST 解析器。

贴图和颜色节点同样采用完整命名空间；普通材质不再调用不适用的 ShaderFX 更新。
颜色常量节点未注册时按需加载 Maya 自带 `lookdevKit`，不需要外部 CAST 插件。

纯动画要求已有有效工具包组装，单武器显式路由手臂 `j_gun`，双持识别左右侧后
替换对应片段。菜单与启用的 **内置 CAST 拖入处理** 共用入口；导入被拒绝时保留
错误，不回退到外部转换器。不支持的混合模型/动画、Instance 容器和多文件拖入
会明确拒绝，请使用分开的模型与动画输入。普通“文件→导入”或明确选择外部
`Cast` 不会被这个入口重定向；关闭拖入开关也会恢复 Maya 默认处理。

## 独立导出

Maya 菜单新增 **Export FBX... / 单独导出 FBX…** 和
**Export SMD... / 单独导出 SMD…**。无需重新挂载，也无需打开构建器的输出勾选。
对话框明确选择静态模型或当前动画、整数帧范围和原单位/米制输出。

- FBX：导出当前场景的模型及蒙皮，可选烘焙动画；普通 Maya 场景也可使用。
- 静态 SMD：导出当前有效工具包组装体的模型、骨架及权重。
- 动画 SMD：仅骨架与动画帧，不包含网格，也不记录 DQS 或帧率。

导出在独立 `mayapy` 场景副本中完成，单位转换和动画烘焙不会改动工作场景。
每次只保留选定的 FBX 或 SMD 文件，临时 MA、CAST、报告及配置随操作结束清理。
已有文件使用 `_v001` 等后缀，取消操作不写文件，失败仍显示错误，成功只更新状态。

无输出挂载后，仍可使用 **Save Current Result / 保存当前结果**：读取当前构建器
或保存设置中勾选的格式，首次分配输出路径后写入文件。

本版未加入 MAX 输出。Maya 保持 CAST 2.01 基线及原骨架/网格/蒙皮算法，加入上述
材质名称修复；Blender CAST 2.00 和输出默认行为不变，仅同步发布版本。

## 验证范围

2026-10-13 已通过的 Windows 后台验证：

- Python 3.14：59 个源码、8 个 Maya 运行文件的 Python 3.7 语法、两种后端
  完整性、17 项发布构建回归、9 项独立导出事务及中英文菜单/取消/卸载契约。
- Maya 2027 / Python 3.13.9：源码、安装版中文入口及中文安装包的 CAST gateway，
  检查模型/材质隔离、同名根材质保护、File/Color 槽、单/双安全路由、输入拒绝、
  主错误保留和失败清理。颜色节点按需加载及移除外部 CAST 后的独立运行也已通过。
- 用户提供的真实模型与动画：统一入口及拖入各采样 0–238 的全部 239 帧，
  安装版与源码世界矩阵最大差 0；挂点最大差 0.182 cm / 0.181°。外部 CAST 未加载，
  原文件 SHA-256 不变。实体武器顶点检查也通过；资源及诊断场景不随发布包分发。
- 独立 FBX/SMD 的静态/动画、原单位/米制、普通场景与防覆盖导出通过真实 worker
  检查，工作场景保持不变；英文安装包完成 8 个导出案例，验证 `10 ft → 3.048 m`。
- 既有 CAST 2.01、私有后端共存/重载、批量蒙皮、无模块文件名拖入，以及单/双持
  四格式动画与米制回归通过。无输出挂载、首次保存和偏好迁移也已检查。
- Maya 中英文、Blender 中英文四个安装包分别在 Maya 2027、Blender 5.2.1 LTS
  的隔离配置下通过安装与对应工作流验证。

GitHub Actions 的 Python 3.11、3.14 检查结果见仓库 Actions。Maya 2022 仍为
Python 3.7 兼容性目标；后台测试不等同于新增人工 GUI 鼠标验收。
